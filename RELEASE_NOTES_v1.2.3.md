# SST Log Analyser v1.2.3 Release Notes

Release date: 2026-07-27

## Channel finder

- Replaced the general Search field with a Channel finder inside `Channels / Pins`.
- Enter a value such as `36`, `CH36`, or `Channel 36`, then press Enter or click the search icon.
- The matching Channel is selected, scrolled into view, and associated with its 128-Channel page range.
- Invalid or unavailable Channel values are reported in the status bar.
- Search no longer filters Test Item names or Diagnostics heatmap data.

## Included from v1.2.2

- Main Chart and all four Diagnostics panels can export the current visible state to PNG.
- Default image names use `TestItem - Module - CH - yyyyMMdd-HHmmss.png`.
